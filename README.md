# FF Events & Updates 🎮

A fast web app to track Free Fire splash banners, announcements, and upcoming events across 15 global servers.

## Features
* **Global Servers:** Monitor events in 15 regions (ME, IND, BR, NA, etc.).
* **Banners & News:** View high-quality splash banners and in-game news.
* **Multi-Language:** Switch banner languages and toggle the UI between English and Arabic.
* **Installable (PWA):** Install the website directly to your phone or PC as an app.

## Tech Stack
* **Frontend:** HTML, CSS, JavaScript.
* **Backend:** Python (Flask), Vercel.

# أحداث وتحديثات فري فاير 🎮

تطبيق ويب سريع لمتابعة صور البداية (Splash Banners) وإعلانات وأحداث لعبة فري فاير القادمة في 15 سيرفر عالمي.

## الميزات
* **سيرفرات عالمية:** متابعة الأحداث في 15 منطقة (الشرق الأوسط، الهند، البرازيل وغيرها).
* **البنرات والأخبار:** عرض صور البداية الترويجية والأخبار داخل اللعبة.
* **لغات متعددة:** تغيير لغة البنرات والتبديل بين الواجهة العربية والإنجليزية بسهولة.
* **تطبيق قابل للتثبيت (PWA):** يمكنك تثبيت الموقع مباشرة على هاتفك أو الكمبيوتر كتطبيق.

## التقنيات
* **الواجهة:** HTML, CSS, JavaScript.
* **الخادم (API):** Python (Flask), Vercel.
